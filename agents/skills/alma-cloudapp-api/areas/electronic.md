# Electronic resources API

Snapshot: 8 paths and 15 operations.

Coverage includes electronic collections, electronic services, and portfolios.

## Cloud App cautions

- Preserve the collection, service, and portfolio hierarchy.
- Verify identifiers and owning resources before updates or deletion.
- Availability and activation changes may affect discovery and access.
- Treat coverage, linking, proxy, and library availability data as structured
  domain data rather than display strings.
- Read the complete current representation before replacement updates.
- Confirm activation, deletion, and broad availability changes explicitly.
- Account for institution, library, and Community Zone relationships where the
  operation supports them.
- Establish electronic-resource roles independently from the API-key
  permission area.

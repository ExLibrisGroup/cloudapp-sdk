# Resource Sharing Directory Member API

Snapshot: 3 paths and 4 operations.

Coverage includes listing directory members, retrieving a member, and
localizing a member as a partner.

## Cloud App cautions

- Preserve the published `/RSDirectoryMember` path capitalization.
- Distinguish a directory member from an already localized institutional
  resource-sharing partner.
- Localization is a state-changing action even though it begins with shared
  directory data.
- Confirm the selected partner code and intended institution before
  localization.
- Treat duplicate or already-localized outcomes explicitly.
- Establish the required resource-sharing configuration role separately from
  API-key permissions.
